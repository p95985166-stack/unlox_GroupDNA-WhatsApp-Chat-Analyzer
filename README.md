# 📱 GroupDNA – WhatsApp Chat Analyzer

> Transforming WhatsApp conversations into meaningful insights using Python and NumPy.

## 📖 Overview

GroupDNA is a Python-based WhatsApp chat analyzer that processes exported chat files and generates meaningful insights about participant activity, communication patterns, response behaviour, and group dynamics.

The project was built using Python fundamentals, NumPy, and the datetime module without using advanced data analysis libraries such as Pandas.

---

## ✨ Features

- 📂 Chat Parsing
- 👥 Group Overview
- 📊 Participant Statistics
- 📅 Most Active Day
- 🕒 Most Active Hour
- 🔥 NumPy Activity Heatmap
- 💬 Top Word Analysis
- ⏱ Response Time Analysis
- 🧠 Personality Archetypes
- 🎖 Fun Group Awards
- 🤖 AI-style Group Summary
- 📈 Communication Insights
